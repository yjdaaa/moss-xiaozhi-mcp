# 项目全局功能白话字典

适用项目：小智本地能力助手

本文档用于团队培训、交接、销售演示、运营说明和长期维护。目标是让没有专业背景的人，也能快速看懂这个项目能做什么、用户怎么用、哪些地方有风险、以后新增功能时该怎么维护说明。

---

### 一、核心业务主线（用户是怎么用这个产品的）

1. 用户对小智设备说出需求，例如“打开微信”“生成一张文字图片”“看看激光机状态”“帮我准备雕刻这张图”。

2. 小智把用户的话交给本地助手，本地助手判断这件事应该由电脑、摄像头、智能家居、激光机，还是图片生成能力来完成。

3. 如果是低风险任务，例如打开软件、打开网页、生成文件、查询状态，系统会直接处理并把结果告诉用户。

4. 如果是高风险任务，例如启动激光、切割材料、让机器移动、修改机器设置，系统必须先复述关键信息，并要求用户明确确认。

5. 用户确认后，系统按用户选择的方式执行任务，并持续反馈成功、失败、当前状态或下一步建议。

6. 对需要长期复用的内容，例如材料参数、测试结果、生成文件、加工任务、设备连接信息，系统会保留记录，方便下次继续使用或排查问题。

### 三、容易被忽略的“隐形功能”

| 隐形功能 | 为什么容易被忽略 | 白话说明 | 影响范围 |
| :--- | :--- | :--- | :--- |
| 功能存在不等于可用 | 看到项目里有某能力，不代表小智能用 | 有些能力需要管理员开启，有些能力默认关闭，有些需要设置完整后才能出现。 | 影响摄像头、智能家居、桌面激光软件 |
| 小智端和本地端分工 | 用户容易以为所有能力都在小智设备里 | 小智负责听用户说话和展示结果，本地助手负责调用电脑和本地设备。 | 影响培训、排障、部署 |
| 高风险动作二次确认 | 用户可能觉得“说了开始”就该马上执行 | 激光启动、切割、移动、改设置等必须先确认，避免误伤、误切、误动；底层发送工具也会用 `confirmed` 参数拦截未确认请求。 | 影响激光全流程 |
| 只读探测 | 查询状态和真正执行动作不是一回事 | 系统可以默认查看设备状态，但不能默认执行会改变设备状态的动作。 | 影响网络激光设备、故障排查 |
| 设备预检失败不续跑 | 用户可能开机后以为任务会继续 | 为避免用户开机瞬间机器自动执行，设备在线检查失败后，本次请求直接结束，必须重新确认启动。 | 影响串口激光、网络激光、任务启动 |
| 不自动猜设备地址 | 用户可能希望系统自己找到设备 | 出于安全和准确性，系统不会编造设备位置或账号信息。 | 影响网络设备、摄像头、智能家居 |
| 文件生成与机器启动分离 | 用户可能以为生成文件就是开始加工 | 生成图片、匹配已有加工文件或生成加工文件都只是准备材料，真正启动机器需要单独确认。用户说“帮我刻 xxx”可先匹配预制 `.gcode` / `.nc`，但不会绕过安全确认。 | 影响文字图片、激光任务、工具路由 |
| 材料参数沉淀 | 用户可能每次都重新试参数 | 系统可以保存材料经验，让下次同类加工更快更稳。 | 影响参数推荐、正式加工 |
| 工作范围保护 | 用户只关注图片大小，不知道机器行程限制 | 系统需要拦截超出范围的任务，避免加工失败或设备风险。 | 影响文件生成、任务启动 |
| 操作留痕 | 用户只看最终结果，忽略过程记录 | 失败排查、责任追溯、培训复盘都依赖关键操作记录。 | 影响维护、排障、安全 |
| 敏感信息隔离 | 团队容易把设备地址、密码写进文档 | 私密信息必须放在本机私密设置里，公共文档只写填写规则。 | 影响安全、交接、合规 |
| 默认关闭桌面点击能力 | 桌面自动点击看起来方便 | 这类能力容易点错窗口或按钮，所以应默认关闭，只在完成校准后启用。 | 影响桌面激光软件、电脑操作 |
| 测试不能碰真设备 | 团队容易为了验证功能直接跑机器 | 开发和维护时应尽量模拟验证，避免真实激光、摄像头、桌面点击造成风险。 | 影响质量检查、安全管理 |
| 失败提示白话化 | 晦涩错误用户看不懂 | 系统需要把失败转成“设备没连上”“文件不存在”“设置不完整”等可操作提示。 | 影响所有用户体验 |
| 角色权限边界 | 不是所有人都应该能启动激光 | 查询、生成文件、选择参数可以开放；真正启动机器应限制给可信用户。 | 影响语音权限、激光安全 |

### 四、文档维护与更新规范（给团队看的）

1. 每新增一个功能，必须补进“功能全景字典”：写清楚功能名称、使用场景、系统具体做什么、会影响哪些其他功能。

2. 每新增一个高风险动作，必须同步补进“隐形功能”和“安全规则”：说明是否需要用户确认、是否能默认执行、失败时怎么提醒。

3. 每次修改功能开关、默认参数、设备控制方式或用户说法，都要同步更新培训话术：确保运营、销售、新员工看到文档后，能准确知道“用户怎么说、系统会怎么做、什么时候不能直接做”。
